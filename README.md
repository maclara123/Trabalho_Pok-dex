Pokédex — Consumo de APIs NoSQL com HTTP e Frontend

1. Sobre o projeto

Este projeto foi desenvolvido como atividade prática da disciplina de Engenharia de Software, com o objetivo de consumir uma API pública, armazenar dados em um banco de dados NoSQL e disponibilizar operações HTTP para consultar, cadastrar, atualizar e excluir informações.
O tema escolhido pelo grupo foi a Pokédex, utilizando a PokéAPI como fonte de dados dos Pokémon. Os dados consultados são armazenados localmente no MongoDB, permitindo que a aplicação utilize as informações salvas sem precisar consultar a API pública a cada operação.
